## Contributing screenshots

Full desktop, installer, terminal and file-manager screenshots are best
captured from a **real booted system** (a VM or a USB install of the
latest release). To contribute:

1. Boot the latest Argon ISO in a VM (or on hardware).
2. Take screenshots (the **Print** key runs xfce4-screenshooter) of:
   the desktop, the app menu, the installer, a terminal, the file manager,
   and the Settings manager.
3. Crop/resize to a sane width (≈1280 px), name them clearly
   (e.g. `desktop.png`, `installer.png`), and add them here.
4. Reference them in the README gallery and open a pull request.

Keep file sizes reasonable (PNG, optimized) so the repository stays light.
