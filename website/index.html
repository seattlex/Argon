Argon OS

Privacy first. Security by default.

A hardened Linux distribution built on Kali rolling, developed in Norway. Zero telemetry, encrypted DNS, firewall on, full-disk encryption in the installer — before your first login.

Download Source code

Defaults that respect you

Nothing phones home

No telemetry, no analytics, no crash reporting. The OS transmits nothing about you — verifiable, because every build script is public.

Encrypted DNS

DNS-over-TLS to privacy-respecting resolvers system-wide, DNSSEC, and no chatty LAN protocols announcing your machine.

Untrackable Wi-Fi

Randomized MAC addresses while scanning, per-network identities when connected, and your hostname is never sent to DHCP.

Hardened out of the box

Firewall denying inbound, AppArmor enforced, hardened kernel settings, fail2ban, and zero services listening by default.

Always patched

Security updates apply automatically and reboots are never forced. Rolling release: current software, continuously.

Full-disk encryption

The guided installer defaults to LUKS2 encryption with Btrfs — one passphrase and everything on disk is protected.

Built in the open

Every file on an Argon image traces back to a public repository. Build it yourself on Kali rolling: 

sudo apt install live-build git
git clone https://github.com/seattlex/argon
sudo ./argon/scripts/build-iso.sh --variant xfce

The Kali ecosystem, on your terms

Argon tracks Kali rolling, so the full Kali package archive is available through apt — but none of it is preinstalled, and installing a package never opens a port. Your system stays minimal until you decide otherwise.
